# Codes

## Overview
Diretório raiz do código-fonte do sistema de medição e faturamento da Petrobras. Agrupa a camada de processamento de dados (Power Query M) e a camada de interface/automação (Visual Basic for Applications).

## Subdirectories & Boundaries
- CodigosM: [CodigosM](./CodigosM/README.md) - Pipeline de Extração, Transformação e Carga (ETL) composto por 83 consultas M para consolidação de atendimentos, cálculo de QExec, SLA, FDM e armazenagem
- VBA: [VBA](./VBA/README.md) - Módulos procedurais e de auditoria para operação interativa e batch no Microsoft Excel
